# TickNotch

## Смысл (caveman)

TickTick фокус идёт — челка показывать. Задача + время, у выреза, поверх всех окон,
даже fullscreen. Глянул вверх — видно сколько осталось, в прилу лезть не надо.
Клик по бару — карточка задачи прямо там, поверх всего. Cookie раз вставить, дальше само.

## Что это

Меню-бар приложение для macOS 14+. Показывает текущую pomodoro/focus-сессию TickTick
чёрным баром, слитым с вырезом (notch): слева от чёлки — точка состояния и задача,
справа — таймер. Поверх всех приложений, включая fullscreen. Без сторонних зависимостей.

- задача + оставшееся время, локальный тик между опросами (поллинг каждые 2 с);
- цвет точки: 🔴 фокус, 🟢 перерыв, 🟡 пауза (+⏸ у таймера);
- нет активной сессии — бар скрыт;
- **клик по бару — плавающее окно задачи поверх экрана** (включая fullscreen): `WKWebView`
  с веб-клиентом TickTick, авторизованным нашим cookie `t`, открытый на детали задачи фокуса
  (`https://ticktick.com/webapp/#p/{projectId}/tasks/{taskId}`). Редактируемо — правки уходят
  в аккаунт. Клик мимо окна или Esc — закрыть. Клик ловится глобальным монитором мыши по
  координатам бара (строка меню/вырез перехватывают клики, окно их не получает);
- меню-бар: скрыть/показать оверлей, **запуск при входе в систему**, ввести cookie,
  скопировать последний ответ API (для отладки), открыть TickTick, выход;
- cookie хранится в защищённом файле `~/Library/Application Support/TickNotch/cookie` (права 0600);
- на 401 и сетевых ошибках — бэкофф и скрытие бара, приложение не падает.

На Mac без выреза бар встаёт по центру вплотную к верхнему краю экрана.

## Синк с приложением TickTick

Отдельного «API приложения» нет: десктоп-прила, телефон и веб ходят в один сервер
(`ms.ticktick.com`). Запущенный фокус синкается между устройствами именно через него —
а TickNotch этот же сервер и опрашивает. Поэтому **бар зеркалит ровно то, что идёт
в приложении** (ты запускаешь помидор в приле → прила пушит на сервер → TickNotch читает).
Cookie нужен только для авторизации; данные те же, что видит прила.

## Автозапуск при входе

Меню-бар → «Запускать при входе» (через `SMAppService`, macOS 13+). Для надёжной
регистрации держи `TickNotch.app` в `/Applications` (ad-hoc сборка из `build/` тоже
регистрируется, но при перемещении бандла ссылку придётся переключить заново).

## Сборка

**Вариант A — без Xcode** (хватает Command Line Tools):

```sh
./build.sh
open build/TickNotch.app
```

**Вариант B — Xcode**: открой `TickNotch.xcodeproj`, схема TickNotch, ⌘R.

## Как запустить

TickNotch — **menu-bar приложение**: нет окна и нет иконки в Dock. После `open` оно живёт
в строке меню (значок таймера справа вверху) — через него cookie/оверлей/выход. Пока идёт
фокус-сессия, у выреза появляется бар. Установи в `/Applications` и запускай оттуда:

```sh
open /Applications/TickNotch.app
```

## Cookie TickTick

Официального API для pomodoro нет — используется приватный веб-API, auth через cookie.

1. Залогинься на [ticktick.com](https://ticktick.com/webapp) в браузере.
2. DevTools (⌥⌘I) → **Application → Cookies → https://ticktick.com** → скопируй значение cookie **`t`**.
   Надёжнее: вкладка **Network** → любой запрос к `api.ticktick.com` → Headers → скопируй
   весь заголовок **Cookie** целиком (там же будет `_csrf_token`).
3. Запусти TickNotch → окно ввода откроется само (или меню-бар → «Ввести cookie…») →
   вставь → «Сохранить и проверить».

Токен живёт долго (недели/месяцы), но протухает при разлогине. Симптом — «⚠️ Cookie
недействителен (401)» в меню: повтори шаги.

⚠️ Cookie `t` даёт полный доступ к аккаунту TickTick — никому не пересылай. Хранится
локально в `~/Library/Application Support/TickNotch/cookie` (0600, только твой аккаунт).

> Почему не Keychain: приложение подписано ad-hoc, а Keychain привязывает доступ к подписи
> кода — каждая пересборка меняла подпись, и macOS **бесконечно спрашивал пароль** от login-keychain.
> Файл под аккаунтом от этого свободен. Если поставишь стабильную подпись (Developer ID) — можно
> вернуть Keychain.

## Отладка / доводка API

Приватный API не документирован; что подтверждено, а что гипотеза — в [API_NOTES.md](API_NOTES.md).
Если капсула показывает странное время/состояние: меню-бар → «Скопировать последний ответ API»
и сверь поля `current` с гипотезами в `FocusParser` (TickNotch/FocusModels.swift) — коды
статусов правятся там в одном месте.

## Замечания

- `build.sh` подписывает ad-hoc. Cookie в файле (см. выше), так что промптов пароля нет.
- Приватный API может измениться без предупреждения; использование формально нарушает ToS TickTick — на свой страх и риск.
